# Datasets

Los datasets originales no se suben a GitHub.

Para ejecutar el proyecto, coloca DroneFace localmente en:

```text
data/DroneFace/open_data_set/
```

Estructura esperada:

```text
data/DroneFace/open_data_set/
|-- photos_all/
|-- photos_all_faces/
|-- portraits/
|-- trio_cam/
|-- trio_gp/
`-- LICENCE.md
```

La carpeta `data/DroneFace/open_data_set/` esta incluida en `.gitignore` para respetar restricciones de licencia y evitar subir archivos pesados.
